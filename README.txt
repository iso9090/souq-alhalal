سوق الحلال الإلكتروني
موقع عربي RTL للإمارات ومصر، للبيع المباشر والمزادات، باستخدام Firebase Auth Phone وFirestore.
السوقان منفصلان في القوائم، والحساب والرسائل والطلبات متاحة عبر البلدين. بيانات legacy بدون country تعامل كالإمارات حيث يطبق المنطق الحالي.
البيع الأساسي والشراء والمزايدة والتسجيل مجانية، دون اشتراك إلزامي أو عمولة إطلاق.
الخدمات الاختيارية وأسعارها في MONETIZATION_PLAN.md. التوثيق يحتاج اعتمادًا موثوقًا.
الدفع التجريبي فقط: payment-demo.html لا يكتب أي شيء إلى Firestore. الدفع الحقيقي غير مفعل.
الإدارة تعتمد على custom claim admin=true. أداة admin-tools موثوقة فقط ولا تُشغّل من المتصفح.
لا تضع أسرارًا أو مفاتيح حساب خدمة في كود العميل. إعداد Firebase العام ليس مفتاحًا سريًا؛ الحماية تعتمد على Rules.
النشر الثابت من main عبر GitHub Pages: https://iso9090.github.io/souq-alhalal/
نشر الموقع لا ينشر firestore.rules؛ تحتاج القواعد إلى نشر مستقل بعد الاختبارات المحلية.
شغّل الموقع بخادم HTTP محلي للمعاينة. لا ترسل SMS أو طلبات حقيقية أثناء الاختبارات.
انظر PAYMENT_INTEGRATION_NOTES.md لتصميم الدفع المستقبلي، وLAUNCH_AUDIT.md لنتائج المراجعة وحدود الإطلاق.

المصادقة: Email/Password طريقة مستقلة بلا SMS. Phone Auth محفوظ بالإمارات +971 ومصر +20 وسيعمل SMS عند توفر الخدمة. فشل billing يعرض بديل البريد. لا دمج تلقائي للحسابات.
كلمات المرور تُدار فقط عبر Firebase Auth ولا تُكتب في Firestore أو logs أو التخزين المحلي المخصص. البريد يظهر لصاحب الحساب فقط ولا يُشارك كوسيلة تواصل عامة.
طلب حذف الحساب: حسابي ← حذف الحساب. مجموعة accountDeletionRequests تحفظ UID وحالة الطلب والتوقيت فقط؛ لا حذف تلقائي أو جزئي لهوية Auth. صفحة عامة: delete-account.html.
