# MELKAK Hero asset

Asset: `melkak/assets/world-hero.webp` — 1536 × 512, 89,640 bytes.

Created using the built-in imagegen tool, then encoded as WebP for the local prototype. No CLI/API key or paid project backend was used. The original generated PNG is retained outside Git. Category item illustrations are local SVG fixtures from the preceding prototype, not real sale photographs.

The asset is decorative, AI-generated artwork inspired by the six markets. It is not a geographic map or an exact architectural representation. Country labels, logo, slogan, filters and buttons are HTML, not baked into the bitmap. No domain or app-store availability from reference images was copied or represented as a fact.
